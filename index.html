Aprenda Desenvolvimento Web

Desenvolva seus conhecimentos em tecnologia e aprenda as principais ferramentas utilizadas no desenvolvimento web.

Tecnologias em Destaque

HTML5

Aprenda a criar a estrutura e o conteúdo das páginas utilizando HTML5.

CSS3

Desenvolva layouts modernos, organizados e responsivos com CSS3.

JavaScript

Conheça a linguagem utilizada para adicionar interatividade às páginas web.

C#

Aprenda conceitos de programação utilizando a linguagem C# e o ecossistema .NET.

SQL

Aprenda a consultar, organizar e manipular informações em bancos de dados.

Git

Conheça o controle de versões e aprenda a acompanhar as alterações dos seus projetos.

Sobre o Portal

O Portal Tech ADS foi desenvolvido como projeto acadêmico para demonstrar conhecimentos de HTML5 e CSS3, utilizando estrutura semântica, Flexbox, CSS Grid e responsividade.
